## The mark

A cart whose handle is an arrow pointing up and out: you find the product here and buy it at the
shop. The mark always sits on its cobalt tile, so it works on any background.

| File | Use |
|---|---|
| `mark.svg` | app icon, favicon, avatar |
| `logo-light.svg` | mark and wordmark on light backgrounds |
| `logo-dark.svg` | mark and wordmark on dark backgrounds |

Keep clear space of half the tile's width around the logo. The arrow is always sun yellow and the
cart always white.

## Colour

| Role | Light | Dark |
|---|---|---|
| Cobalt (accent, tile, hero) | `#1F3FBF` | `#8EA6FF` (accent on dark; hero `#16235E`) |
| Sun (the arrow, labels) | `#FFC83D` | `#FFC83D` |
| Ink / text | `#0E1630` | `#E9EDF8` |
| Paper / background | `#F6F8FC` | `#0C1122` |
| Muted text | `#56607A` | `#A2ABC4` |
| Line | `#D0D7E8` | `#2F3957` |
| Box | `#E9EEF9` | `#151C33` |

Cobalt carries the brand; sun is used sparingly, for the arrow and for one label or rule at a time.
Never set body text in sun.

## Type

- **Display:** Archivo ExtraBold for the wordmark and headings, tightly tracked.
- **Text:** the system sans-serif stack.

Archivo is licensed under the SIL Open Font License and is self-hosted on the site; the wordmark
in the logo files is outlined, so the files need no font.
